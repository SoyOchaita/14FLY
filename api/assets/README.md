Place your email logo image here and set MAIL_LOGO_PATH in api/.env.

Recommended file: logo-14fly.png (transparent background, 150-200px width). Examples:

- MAIL_LOGO_PATH=assets/logo-14fly.png
- MAIL_LOGO_PATH=C:\\UMES\\...\\api\\assets\\logo-14fly.png (absolute path)

Alternatively, host it and set MAIL_LOGO_URL to a public HTTPS URL, e.g.:
- MAIL_LOGO_URL=https://your-cdn.example.com/14fly/logo-14fly.png
